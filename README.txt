GITHUB PAGES DEPLOYMENT
1. Extract the ZIP to your computer.
2. Create a new public repository (for example, wedding) on GitHub.
3. Use Add file > Upload files and upload contents of the extracted folder (not the ZIP itself); preserve the assets folder structure.
4. Commit changes. In repository Settings > Pages, set Source to Deploy from a branch, branch main, folder /(root), and Save.
5. Share the three live HTTPS links once Pages shows the site as published.
   https://YOUR_USERNAME.github.io/wedding/
   https://YOUR_USERNAME.github.io/wedding/mehndi-baraat.html
   https://YOUR_USERNAME.github.io/wedding/walima.html

IMPORTANT
- Sharing the raw HTML file over WhatsApp is unreliable. Share published HTTPS URLs.
- Audio starts when guests tap You're Invited; WhatsApp's in-app viewer may still block or mute audio, in which case guests can open the link in Chrome/Safari.
- Images and song are hosted locally under assets; the page does not depend on the original music CDN. Google Fonts and the decorative logo may still load from external servers.
- The venue map screenshots link to the original Google Maps directions.
- The repository and website are public: avoid uploading any private information.
